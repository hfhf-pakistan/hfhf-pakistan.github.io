Hope For Humanity Foundation website
1. Keep index.html and logo.jpg in the same folder.
2. Open index.html in a browser to preview.
3. To publish free with GitHub Pages:
   - Create/sign in to a GitHub account.
   - Create a new public repository named hope-for-humanity-foundation.
   - Upload index.html and logo.jpg to the repository root.
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Select main and /(root), then Save.
   - GitHub will provide the live website address.
Before publishing, verify the organization's legal wording, project descriptions, email and address.
